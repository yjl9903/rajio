## v0.2.1 · 2026-06-26

### Features

- 支持 OpenAI 兼容的 Whisper 转写服务。
- 会话记录 CLI 版本，加载时拒绝版本缺失或不一致的会话。

## v0.2.0 · 2026-06-26

### Features

- 默认使用 ElevenLabs 转写，支持说话人识别、词级时间戳和服务连通性检查。
- 支持从指定阶段重置流程，以及提取和重新转写音频片段。
- 支持有序字幕补丁、插入片段，以及多片段查询和问题分页。
- 完善字幕字数、断句和时间轴检查，支持检查豁免与修复建议。
- 精简检查与提交摘要，补充阶段状态和失败处理提示。
- 上线官网、使用文档和字幕示例，发布包附带 Agent skill。

### Bugfixes

- 修正媒体相对路径解析，避免误建会话。
- 修复自动阶段失败漏报，以及翻译阶段丢失检查豁免的问题。
- 修复描述文件解析和建议补丁格式，拒绝乱码与非法字符。
- 修正命令输出摘要，并避免管道提前关闭时崩溃。
