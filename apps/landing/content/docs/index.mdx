# Rajio Docs

Rajio is a TypeScript CLI for turning Japanese seiyuu radio audio into reviewed
transcripts, Chinese translations, and subtitle exports.

## What you can build

- Resumable session-based transcript and translation workflows.
- Validated segment files for human or agent review.
- Final SRT and ASS subtitles for publishing.
