# rajio

[![CI](https://github.com/yjl9903/rajio/actions/workflows/ci.yml/badge.svg)](https://github.com/yjl9903/rajio/actions/workflows/ci.yml)

## Installtion

```bash
npm i -g rajio
```

## Usage

1. Add rajio skill to your agent.

```bash
npx skills add https://github.com/yjl9903/rajio
```

2. Invoke `$rajio` skill, and let agent guide you how to use it.
